# oscdr — ブラインド・オーバーサンプリング CDR (Veryl)

Gowin EasyCDR IP と同じ物理層 (OSIDES32: 4 相 500MHz × IODELAY 2 系統 = 4 サンプル/UI @1Gbps、
PCLK 125MHz 毎に 32 サンプル) の上で動く、自前のクロック・データリカバリ。
IP と違い**位相選択を凍結できる**ので、BERT と組み合わせたアイスキャンができる。

```
 OSIDES32 (32 samples/clk, [0]=最古) --> OsCdr --> bits[8:0] + nbits(7/8/9) --> BitGearbox --> 16bit + valid
```

## OsCdr のアルゴリズム (os_cdr.veryl)

1. 遷移検出 `t[i] = s[i]^s[i-1]` (前ワードの最終サンプルを跨いで) → クラス `i mod 4` 毎に計数 (レジスタ段)
2. IIR 平滑化 `A[c] += cnt[c] − A[c]/2^IIR`
3. **毎ワード**、データサンプル候補 d の「両隣のエッジ数」`cost(d) = A[d] + A[d+1]` を比較し、隣が
   `HYST` 以上小さければポインタを ±1 ステップ。判定式は代数的に簡約 (`acc[d+2]+H < acc[d]` 等) して
   1 段の 6bit 比較にし、4 候補分を並列計算してから dsel で選ぶ (タイミング対策)
4. **方向適応ヒステリシス**: 直前と同じ方向のステップはヒステリシス無し (周波数オフセット追従を
   速く)、逆方向は `HYST` (ディザ抑制)。これで ±5000 ppm でも誤り 0
5. ビット抽出: ポインタ `posu` (0..5 = サンプル −1..4) から 4 サンプル刻みで取り出す。ワード境界を
   跨ぐステップで 7 または 9 ビットになる = プレシオクロナスなビットスリップ。`posu` は 6 値しか
   取らないので case による静的スライス
6. ロック: 選択サンプル隣接クラスのエッジが総数の 1/4 以下でセット、1/2 超が 8 ワード続けば解除
   (シュミット + 持続時間)。全ゼロ/無信号は活性条件で除外
7. `i_freeze` で 3〜4 を停止 (アイスキャン用)。`o_slip` はポインタ移動パルス

## テスト (`veryl test`)

Verilator。TX PRBS7 を UI=1ns×(1+ppm) で生成し、0.25ns 間隔 32 サンプル/ワードのサンプラ
(初期位相・エッジジッタ付き) で受け、ギアボックス後の 16bit 語を自己同期 PRBS7 チェッカで検査。

| テスト | 結果 |
|---|---|
| 0 ppm / ±1000 ppm / ±5000 ppm | 誤り 0、スリップ数は理論値 (|ppm|×bits×4/1e6) と一致 |
| ジッタ 0.15 UI (p-p 0.3 UI) | 誤り 0 |
| scan (凍結 + サンプル位置掃引) | エッジ位置でのみ誤り (挙動確認用) |

## 実機 (Tang Primer 25K, eda/easycdr_bert)

- 純正 IP を置き換えて PRBS ロック、1.000 Gbps、誤り 0、注入 3 → 3 (2026-09-13)
- アイスキャン: RX 凍結 + TX PLLA 動的位相シフト (125ps/ステップ) → 周期 8 ステップ = 1 UI の
  バスタブ、開口 ≈ 0.5 UI (BER < 1e-8 の点 4〜5 個)、エッジ側 3 点は 1e-4〜閉口
- リソース (BERT 全体): LUT 1089 / ALU 427 / FF 1035、125MHz で setup +0.25ns

## 実機で分かった制約 (重要)

- **OSIDES32 内蔵 IODELAY は静的 (C_STATIC_DLY) 専用。`DYN_DLY_EN="TRUE"` にすると静的遅延まで
  無効になり、a/b コピーが同一時刻 = 2 サンプル/UI に退化する** (純正 IP は DYN/ADAPT=FALSE、
  SDTAP/VALUE/DLYSTEP を GND 固定。この構成に揃えると TX 位相掃引で遷移クラスが 4 つを ~250ps ずつ
  巡回 = 4 サンプル/UI が実在)。動的タップ変更は不可
- OSIDES32 の D は IBUF 直結必須 (CK3001) → 間に IODELAY は入れられない
- RX PLL の動的位相シフトで FCLK を運転中に動かすと OSIDES32 内部の FCLK→PCLK 転送同期が壊れ、
  リセットまで復旧しない (DYN_PE_SEL=TRUE では静的 PE 位相も消え、起動時に DPS パルスで復元が必要)
  → PLL 追従型 CDR は不成立。TX 側 DPS (アイスキャン) は問題なし
- 純正 IP は 4 相クロックを DHCE でゲート (リセット中停止) してから OSIDES32/CLKDIV に供給している。
  同じ構成にしてある (`oscdr_phy_gw5a.v`)
- TX 側 OSER8 → IODELAY → OBUF は合成可能でタップも効く (12.5ps/タップ確認) が、遅延線が
  1Gbps 信号を劣化させ PRBS がロックしない → 不採用
- 使えるスキャン軸は PLLA の動的位相シフト (VCO/8 = 125ps @ VCO 1GHz。GW5A-25 の VCO は
  700〜1400MHz なので 1/8 UI が限界)
