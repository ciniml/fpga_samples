# 依頼: Type-C Alt Mode基板の主要IC 2点のKiCadフットプリント作成

このファイルは、KiCadが動作しているPC上のセッションへの作業指示書です。
DisplayPortソースFPGA用のType-C Alt Mode基板(FUSB302B + HD3SS460構成)の
回路設計で使用します。

## 成果物

- KiCadプロジェクトローカルのフットプリントライブラリ(例:
  `typec_board.pretty/`)に以下2点を用意すること
  1. **TI HD3SS460RHR** 用フットプリント
  2. **onsemi FUSB302BMPX** 用フットプリント
- 各フットプリントについて、下記チェックリストの確認結果を報告すること

## 方針: まず標準ライブラリを探し、無ければ作る

KiCad標準ライブラリに適合品がある場合はそれを使用(または複製して
リネーム)すること。確認先:

- `Package_DFN_QFN` ライブラリ内で、後述のパッケージ寸法(ボディサイズ・
  ピン数・ピッチ・EP寸法)に**完全一致**するものを検索
- TIパッケージはKiCad標準に `Texas_*` 系の専用フットプリントが存在する
  ことがあるので `RHR` でも検索

一致判定は「ピン数・ピッチ・ボディ寸法・サーマルパッド寸法」の4点全てで
行い、近似品の流用はしないこと。

## 対象パッケージ情報

### 1. TI HD3SS460 (パッケージコード RHR / WQFN-28)

- データシート: https://www.ti.com/lit/ds/symlink/hd3ss460.pdf
  (末尾のMechanical Data / RHR0028 パッケージ図面と、
  Recommended Land Pattern を必ず参照して寸法を取ること)
- 概要: WQFN-28、長方形ボディ(3.5mm × 5.5mm級)、0.5mmピッチ、
  露出サーマルパッド付き
- **注意: 上記の概要値は目安。必ずデータシートの図面から
  正確な寸法・パッド設計値を採ること**

### 2. onsemi FUSB302B (発注型番 FUSB302BMPX / パッケージ MLP(QFN)-14)

- データシート: https://www.onsemi.com/download/data-sheet/pdf/fusb302b-d.pdf
  (Package Dimensions の MLP-14 図面を参照)
- 概要: 14ピンMLP(QFN系)、2.5mm × 2.5mm級、露出パッド付き
- 同型番ファミリにWLCSP品(FUSB302BUCX等)があるが、**採用するのは
  QFN系のMPX**。取り違えないこと
- 同じく寸法は必ずデータシート図面から採ること

## フットプリント作成規約(KiCad標準に準拠)

1. 命名: `HD3SS460_WQFN-28_RHR` / `FUSB302B_MLP-14` のように
   部品名+パッケージが分かる名前
2. パッド: データシートの Recommended Land Pattern があればその値を優先。
   無い場合はIPC-7351 Nominal相当で生成(KiCadのフットプリントウィザード
   のQFNジェネレータ使用可)
3. サーマルパッド(EP):
   - パッド番号は「最終ピン番号+1」(28ピンなら29、14ピンなら15)
   - ペーストは全面ベタにせず**4〜6分割・被覆率50〜70%**に設定
   - ビア(放熱用)はフットプリントには含めず基板側で打つ
4. シルク: ピン1マーカー必須(パッド上に掛からないこと)、
   リフロー後も見える位置に
5. F.Fabレイヤ: 実体外形+ピン1マーク、Ref/Value配置
6. F.Courtyard: パッケージ外形+0.25mmクリアランス
7. 3Dモデル: 標準ライブラリに流用できるQFNモデルがあれば割当
   (寸法違いでも当面は目視確認用として可、無ければ省略可)

## 完了時のチェックリスト(報告に含めること)

- [ ] ピン数・ピッチ・ボディ寸法・EP寸法がデータシート図面と一致
- [ ] パッド寸法の出典(データシート推奨 or IPC Nominal)を明記
- [ ] ピン1の位置と番号回りの向き(反時計回り)を図面と照合
- [ ] EPのパッド番号(29 / 15)とペースト分割の設定
- [ ] DRC(フットプリントエディタ上のパッド重なり等)エラーなし
- [ ] 標準ライブラリ流用の場合: 流用元フットプリント名を報告

## 補足(回路側コンテキスト、参考)

- この2つのICの役割: FUSB302B = USB PD PHY (CC1/CC2, I2C接続)、
  HD3SS460 = 4レーンDP + SBUの表裏反転mux
- ネット接続や周辺部品はリポジトリの
  `rtl/displayport/doc/typec_board_kicad_notes.md` を参照
- 基板の他の主要部品(Type-Cレセプタクル、ロードスイッチ、ESD)は
  標準ライブラリ品または部品確定後に別途依頼予定
