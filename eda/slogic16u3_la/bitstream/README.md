# SLogic16U3 ロジアナ ビルド済み位流

合成・配置配線済みで、タイミングを満たしたビルドです。フラッシュ用にしてあり、次の multiboot アドレスは
0x800000 (MODE を押すと DFU に戻る) です。書き込み手順は `../README.md` の「フラッシュへの書き込み」にあります。

| ファイル | 用途 |
|---|---|
| `slogic16u3_la.bin` | 公式 DFU ツールでフラッシュ 0x0 に書く |
| `slogic16u3_la.fs` | 同じ中身。JTAG の SRAM ロード (`gowin-prog sram`) 用で、DFU に入れなくなったときの復旧にも使う |
| `SHA256SUMS` | チェックサム |

## 出所

| 項目 | 内容 |
|---|---|
| 版 | v2 (ハードウェアトリガつき、ID レジスタ 0x02004C41) |
| ソース | この位流を入れたコミットの rtl/la、rtl/usb3、eda/slogic16u3_la |
| ビルド | `make PLACE_OPT=4 ROUTE_OPT=2 LA_TIMEOUT=2600 TAG=rep` (Gowin EDA 1.9.12.03)、続けて同じ引数で `make ... dfu` (`host/mkdfu.py`) を実行し、ヘッダの次 multiboot アドレスを 0x000000 → 0x800000 に書き換え。同じソース・同じ引数で作り直すと、`.bin` はバイト単位で一致した (`.fs` は作成時刻の行だけ違う) |
| タイミング | pclk 125.039 MHz (制約 125)、sclk 104.821 MHz (制約 100)、TNS 0 |
| 資源 | ロジック 12288 / 15120 (82 %)、CLS 94 %、BSRAM 26 / 35 |
| USERCODE | 0x00007D6C |
| USB | 1209:0001 "USB SS Sample" (USB 3.0、WinUSB 用 MS OS 2.0 記述子つき) |

2026-10-12 の実機確認:
- この `.bin` を公式 DFU ツールで 0x0 に書き、`Verify OK` (書き込み前に `host/dfu_backup.py` で v1 を退避)。
- MODE でフラッシュから起動し、ID レジスタ 0x02004C41、USB 5 Gbps で列挙。
- 800 MS/s × 4 ch を 3 秒取り込み、400.56 MB/s で取りこぼしがなかった (SRAM ロードでも同じ)。
- 2 つのグループにまたがるハードウェアトリガ (CH7 の立ち上がりかつ CH15 = 1) が発火し、両グループの位置がそろった。

v1 (トリガなし、コミット 672caf5 のソース) は公式 DFU ツールでの書き込み、フラッシュからの起動、MODE での DFU
復帰まで確認済みでした。必要なら git の履歴 (コミット 41354eb) から取り出せます。

作り直すときは、タイミングが PnR 次第でぶれることに注意してください (`../README.md` の「ビルド」)。
