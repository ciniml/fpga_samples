# hub75_stg — 縦スクロールシューティング (HUB75 パネル用)

`eda/ethernet_hub75` (DK_LED-RXCARD) のパネルに出すゲーム。PC 上で 60 fps で動かし、128x192 (64x64 パネル 2 × 3 枚) の
画面を UDP (udpvideosend と同じ形式) で表示の左上に送る。16 枚版 (256x256) の左上 2 × 3 枚、または 6 枚版 (128x192) で遊べる。

```
cargo build --release
./target/release/hub75_stg                    # 16 枚版 (256x256 の左上)。この端末のキーで操作
./target/release/hub75_stg --frame 128x192    # 6 枚版
./target/release/hub75_stg --auto             # デモ (ボットが遊ぶ)。端末がなくても動く
```

- **操作:** 矢印 / WASD で移動、ショットは自動、X で bomb、Enter で開始、P で一時停止、Q / Esc で終了
- **キー入力:** 端末から読む (ssh / tmux 越しでも可)。キーを離したことを端末が通知する場合 (kitty キーボードプロトコル: kitty、
  WezTerm、foot、Ghostty など) はそのとおりに、通知しない端末ではキーリピートが続く間を押しっぱなしとみなす
  (最初の 1 回は 0.55 s 保持するので、軽く叩くと少し流れる。反対方向のキーで即止まる)
- **ゲーム:** 1 ステージ約 40 秒の敵編隊 (正弦波で降りる編隊、V 字、急降下、横切り、砲台) のあと WARNING とボス。ボスは
  体力に応じて 3 種の弾幕 (3 方向の渦、7 方向の扇 + 全方位、2 重の渦) を撃つ。ステージごとに敵の数・弾速が上がる。砲台は
  P (ショット強化、3 段階) / B (bomb) を落とす。bomb は弾を消して画面内の敵全体に大ダメージ。残機 3、ハイスコアは
  `~/.hub75_stg_hi` に保存
- **フレーム:** 毎フレーム送ったあと、ボードの ack (表示の切り替え) を最大 6 ms 待つ。切り替え前に次のフレームを送るとボードが
  捨てるため
- `--snapshots DIR --ticks N` はデバッグ用: パネルにも端末にも触れず、ボットが N tick 遊んで 300 tick ごとの画面を PPM で保存
